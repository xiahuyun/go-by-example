# tx-no-mmap（写不走 mmap 重映射时，基本不被读阻塞）

这个示例演示一个更窄的场景：

- 有长读事务（持有 2 秒）。
- 并发发起一次小写入。
- 该写入尽量复用已有空闲页，不触发文件扩容与 mmap 重映射。

## 运行

在 `etcd/bbolt` 目录执行：

```bash
go run ./tx-no-mmap
```

## 预期现象

- `写事务总耗时` 明显小于读事务持有时间（通常是微秒~毫秒级）。
- `DB 文件大小变化` 为 `delta=0`。

这说明在“不触发 grow/mmap 重映射”的写路径下，写事务通常不会被并发读事务明显阻塞。

## 关键思路

1. 先批量写入再批量删除，制造可复用的空闲页。
2. 再做一次 warmup 写事务，触发 `ReleasePendingPages`，把 pending pages 变成 freelist 可分配页。
3. 测试写事务只更新固定长度 value，尽量避免页增长和重映射路径。
